os-blocky

An OPNsense plugin for blocky, a DNS proxy and ad-blocker. This page is also the signed pkg repository that serves the plugin and the blocky package it depends on.

Install from this repository

On the firewall, as root. blocky is not in the OPNsense package repository, so this repository provides both packages. 

fetch -o /usr/local/etc/pkg/keys/os-blocky.pub \
    https://pyarmak.github.io/os-blocky/os-blocky.pub
fetch -o /usr/local/etc/pkg/repos/OsBlocky.conf \
    https://pyarmak.github.io/os-blocky/OsBlocky.conf
pkg update
pkg install os-blocky

pkg update should report the OsBlocky repository as signed and trusted. If it says unsigned, the public key is not where the repository configuration expects it.

From then on the plugin appears under System → Firmware → Plugins alongside the official ones and upgrades with the rest of the system.

Install without adding the repository

Every build is also published as a GitHub release, so the packages can be installed directly. Note that blocky must be installed first — it is a dependency of the plugin. 

pkg add https://github.com/pyarmak/os-blocky/releases/download/latest/blocky.pkg
pkg add https://github.com/pyarmak/os-blocky/releases/download/latest/os-blocky.pkg
The plugin ships a firmware hook that writes /usr/local/etc/pkg/repos/OsBlocky.conf when it is installed, so even a sideloaded install ends up subscribed to this repository. Delete that file if you would rather manage updates by hand.

Repository details

  • Target: OPNsense 26.7 (FreeBSD:15:amd64)
  • Catalogue URL: https://pyarmak.github.io/os-blocky/pkg/26.7/latest
  • Signing: RSA, signature_type: pubkey — os-blocky.pub
  • Priority 5, below the OPNsense repository, so it can never shadow a core package
  • Only the newest build of each package is kept in the catalogue; older builds stay available as release assets

What the plugin provides

  • Services → Blocky → Settings — the full blocky configuration across eleven tabs
  • Status — blocking state with auto re-enable countdown, 24 hour statistics, and a lookup tool
  • Query Log — browser for blocky's per-query logs
  • Two dashboard widgets, service integration, and the service log in the standard log viewer
The plugin listens on port 5300 by default so a fresh install cannot collide with Unbound. To serve the network on port 53, move or disable Unbound first.
